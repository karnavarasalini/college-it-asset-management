# College IT Asset Management System

## Project Overview
The College IT Asset Management System is designed to help a college manage equipment such as laptops, monitors, accessories, and other IT assets. Users can view assets assigned to them, submit service requests, receive notifications, and manage their profile.

## Current User Dashboard Features
- User login/logout interface for demonstration
- Dashboard summary statistics
- Assigned asset management
- Asset search
- Asset category filtering
- Asset details view
- Service request creation and validation
- Dynamic service request list
- Notifications
- Mark a notification as read
- Mark all notifications as read
- User profile and profile editing
- Responsive user interface

## Frontend Module
The frontend currently provides the User Dashboard using HTML, CSS, and vanilla JavaScript. It uses sample client-side data while awaiting backend API integration. No backend or database implementation is described here because those details have not been finalized.

## Future Integration

- Real service request processing
